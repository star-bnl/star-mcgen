# Running UrQMD 4 in STAR

This directory contains an example STAR macro for running the `UrQMD4_0_0` event generator through the STAR `StarPrimaryMaker` framework:

- `starsim.urqmd4.C`

## Macro location

The example macro is located at:

`star-mcgen-urqmd4/StRoot/StarGenerator/macros/starsim.urqmd4.C`

## Basic usage

From a STAR environment with `root4star` available:

```cpp
root4star starsim.urqmd4.C
```

The macro defines a `starsim(...)` entry point with the following arguments:

```cpp
starsim(
  Int_t nevents = 10,
  Int_t rngSeed = 1234,
  const Char_t *tag = "y2018",
  Double_t ecm = 200.0,
  const Char_t *blue = "Au",
  const Char_t *yell = "Au",
  Double_t bmin = 0.0,
  Double_t bmax = 30.0,
  const Char_t *urqmdSet = ""
)
```

The default configuration is an `Au+Au` run at `sqrt(s_NN) = 200 GeV` with an impact-parameter range of `0-30 fm`.

## Example invocations

Run the default `Au+Au` setup:

```cpp
root4star
.L starsim.urqmd4.C
starsim()
```

Run 100 events with a custom random seed:

```cpp
root4star
.L starsim.urqmd4.C
starsim(100, 98765)
```

Run a different beam configuration:

```cpp
root4star
.L starsim.urqmd4.C
starsim(50, 1234, "y2018", 200.0, "Cu", "Cu", 0.0, 20.0)
```

Pass additional UrQMD input commands through the STAR maker attributes:

```cpp
root4star
.L starsim.urqmd4.C
starsim(20, 1234, "y2018", 200.0, "Au", "Au", 0.0, 30.0,
        "cto 40 40;rsd 123456")
```

The command string is written into `UrQMD.in` by the bridge. Separate multiple commands with semicolons.

## What the macro does

The example macro follows the same STAR `starsim` pattern used by the other generator examples:

1. loads the STAR generator support libraries
2. loads the UrQMD4 runtime library
3. creates a `StarPrimaryMaker`
4. constructs `StarUrQMD`
5. configures frame, beams, center-of-mass energy, and impact parameter
6. optionally forwards extra UrQMD commands through the `SET` / `Set` attributes
7. initializes the primary maker
8. runs the standard `gkine`, `gfile`, and `trig(...)` flow

## Output files

With the current macro defaults, STAR writes:

- `urqmd4.starsim.root`
- `urqmd4.starsim.fzd`

The UrQMD bridge also writes an input file named:

- `UrQMD.in`

That file is generated by `StarUrQMD::InitializeUrQMD()` and contains the run configuration consumed by the FORTRAN side of UrQMD.

## Important caveat

The previous diagnostic `assert(0)` in the UrQMD bridge has been removed from `UrQMD4_0_0/StarUrQMD.cxx`, and the example macro now reflects the intended STAR-side setup for running UrQMD 4.

However, the bridge and its integration are still under active development and have not been fully validated for routine production use. Treat this macro as an example configuration and consult `../UrQMD4_0_0/README.md` for the most up-to-date information on remaining limitations and known issues.
